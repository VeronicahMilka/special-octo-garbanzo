# Personal Portfolio

A minimalist, responsive personal portfolio website by Milka Wanjiku Migichi, a software engineering diploma student working toward becoming a full stack developer.

## Features
- Clean light theme with sage green accents
- Sticky navigation with smooth scrolling
- Sections: Hero, About, Skills, Projects, Contact
- Responsive layout for mobile and desktop

## Built With
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Clone the repo:
   `git clone https://github.com/VeronicahMilka/portfolio.git`
2. Open `index.html` in your browser.
